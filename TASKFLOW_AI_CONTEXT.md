## High-Level Project Summary

**What is TaskFlow?**
A peer-to-peer task management and productivity suite. Any user can assign tasks to any other user, forming delegation chains. It includes real-time notifications, deep nested notes (Notion style), and team management.

**Production URLs**
- **Web Frontend:** `https://taskflow-by-crevio.vercel.app` (Deployed on Vercel)
- **Backend API:** Hosted on Render
- **Database:** Aiven MySQL 8 (Cloud)
